# L5 / Signal & Time-Series Workspace

**把自己的工业时序数据，变成可以持续分析的项目。**

[English](README.en.md) · [运行项目](#运行项目) · [架构](docs/architecture.md) · [TripLens 视频](video/README.md)

L5 默认打开 Workspace。你可以创建项目、导入任意列名的数值 CSV、运行异常检测，再把多个区间、分析结果和模拟实验组织为一个长期保存的 **事件（Incident）**。事件工作站保存调查笔记、证据、候选解释和结论，重启后可以继续编辑。Workspace 的 **Process simulator** 提供过程模拟、拓扑调查、报警和干预。**TripLens examples** 使用同一套运行时调查界面。

**Signal catalog、Data quality 和 Signal Explorer** 把多个来源的数据放入同一个工作区：保存信号含义、明确时间关系、定位缺测与采样空档，再用共享窗口浏览原始曲线。CSV 和已保存的模拟输出使用相同的数据管理能力。

## 现在可以做什么

- **Workspace**：创建、打开、重命名和删除项目。一个项目保存多个数据集和多次分析。
- **CSV 导入**：预览列、样本和曲线；支持逗号、分号、Tab、竖线分隔，UTF-8 和常见中文编码。可以指定时间列、数值时间单位，或使用固定采样间隔生成时间轴。
- **通用信号**：保留用户自己的列名，不依赖 TripLens 的 18 通道格式。Max-Z 支持单信号；PCA 支持两个及以上信号。
- **信号目录**：每个信号拥有稳定 ID，可编辑显示名称、单位、类别、说明、设备、标签及跨数据集逻辑测点。支持按来源和语义筛选，直接打开曲线及质量详情。
- **时间与质量**：明确区分相对数值秒、ISO 日期时间和 Unix 时间；日期可指定无时区值的解释时区。检查缺测、重复／无效时间戳、不规则采样、长空档、统计量及可用样本片段。
- **跨源 Signal Explorer**：绝对来源共享 UTC；相对来源可保存明确参考或偏移。不同物理量默认分图，共享观察窗口和游标；同单位、同类别可叠加。保存选择、布局、窗口和游标，重启后重开。
- **Transformation Workspace**：按稳定信号 ID 选择多个来源，转换工程单位，配置共同、全部或自定义时间网格，逐信号重采样、处理重复时间和缺失值，再用表达式计算新变量。实际计算预览显示曲线、质量变化和样本来源；保存配置并生成可直接分析的派生 Dataset。
- **真实分析**：Robust Max-Z、PCA-Q、PCA-T²、EWMA、Page CUSUM、有限窗口 CUSUM、动态 PCA-Q/T²、自适应 Max-Z（Experimental），显示原始测量、异常分数、固定阈值、超阈区间、首次检出时间和相关信号。
- **自由模拟与调查**：以 12 种故障作为模板，调整工况、发生时间、强度、噪声、响应、延迟、随机种子、时长和积分步长；在任意观察时刻选择全部候选并主动调用工具。
- **反事实试验**：选择观测拟合或已知模拟模型，自定义动作时间、预测时域和控制强度，比较多种动作、前次参数结果，按需搜索恢复窗口。
- **分析历史**：每次成功运行自动保存模型、参数和完整结果；可以重新打开、修改参数再运行，或导出 JSON。
- **事件调查工作站**：创建、编辑和归档事件，按状态、标题或时间范围查找；关联多个数据集、分析和异常区间，查看来源窗口的原始曲线、峰值和贡献度。笔记、候选解释、支持／反对证据、结论及模拟实验引用直接保存到 Workspace SQLite。
- **事件时间线与比较**：按实际观察时间组织算法报警、人工记录和模拟实验；筛选来源、类别与时间范围，点击后同步原始曲线与比较窗口。共同／独有报警只在兼容且共同有效观测的时间范围内比较，分数与阈值保留各自尺度。
- **专业调查报告**：从保存的事件直接生成中文报告，包含真实测量曲线、分数与阈值、算法比较、证据、结论和可选模拟方案。提供预览、离线独立 HTML、A4 打印／保存 PDF，以及事件 JSON 导出。
- **本机持久化**：SQLite 保存元数据和任务；原始 CSV、数值数组和结果文件保存到本地目录。关闭浏览器或重启服务不会清空项目。

## 运行项目

需要 Node.js 20.19+ / 22.12+、npm 和 Python 3.12+。

```bash
npm ci
python -m venv .venv
node scripts/python.mjs -m pip install -r requirements.txt
npm run build
npm run serve
```

打开 **http://127.0.0.1:8787**。不需要 API 密钥或云服务。脚本优先使用项目 `.venv`；也可以通过 `PYTHON` 指定解释器。

开发时在两个终端分别运行：

```bash
npm run serve
npm run dev
```

Vite 将 `/api` 请求代理到本机 8787。只有静态前端时仍可进入 TripLens 示例；Workspace 需要 Python 服务。

## 完成一次分析

1. 在首页输入项目名，点击 **Create workspace**。
2. 在 **Datasets** 选择自己的 CSV，检查时间轴和数据预览，点击 **Import and save dataset**。
3. 勾选信号，点击 **Configure analysis**。
4. 设置假定正常的基线区间和位于其后的分析区间。时间输入统一为秒；日期时间数据会显示对应的 UTC 起点。
5. 选择算法和参数，点击 **Run analysis and save**。
6. 查看曲线、阈值、异常区间和相关信号。在 **History** 可以重新打开结果或使用原参数再次分析。
7. 在异常区间卡片或完整异常记录中点击 **创建事件**，修改事件标题、起止时间和说明，再点击 **创建并打开事件**。
8. 从原始分析中选择其他区间，点击 **添加到已有事件**；其他算法或数据集的结果也可以加入同一事件。
9. 在事件工作站保存调查记录和结论。关闭服务后，再次运行 `npm run serve`，从侧边栏 **事件** 打开同一事件继续工作。

正常基线按用户配置的比例分为拟合和阈值校准两段，两段各至少 30 个样本；默认 70% / 30%。分析区间不参与训练或阈值选择。缺失值保留在原数据中；计算时用拟合中位数填充，但原始覆盖率不足、或指定必需信号缺测的行会输出 **abstain**，并重置时序检测和报警确认状态。可配置传感器缺失、噪声、偏置实验，并在 History 比较保存的分析。

## 管理和比较多个数据源

1. 从 **Datasets** 逐份导入 CSV。检查预览中的 `Time interpretation`；Unix 秒／毫秒必须显式选择 **Unix epoch time** 和相应单位。带时区的日期统一保存 UTC 起点；无时区日期使用输入的时区，默认 UTC。
2. 打开 **Signal catalog**，编辑信号名称、单位、类别、设备和标签。相同 `Logical measurement key` 表示用户明确关联的同一物理测点；原始列名继续用于读数据和运行算法。
3. 在 **Data quality** 选择来源，查看总体数量、每信号统计和时间分布。点击缺测、空档、重复时间或无效时间记录，打开对应原始曲线；无效时间记录显示 CSV 行号，并定位到附近有效时间。
4. 在目录勾选多个信号，点击 **Explore selected signals**。绝对时间自动共享 UTC；相对来源默认使用独立时钟。在 **Time relationships** 选择参考数据集或设置带时区的零点，再保存偏移。参考关系满足「来源秒数 + 偏移 = 参考来源秒数」。可沿参考链关联，循环和跨项目引用会被拒绝。
5. 调整共享观察窗口，缩放或移动游标。UTC 窗口输入相对于该轴最早来源时刻；游标数值输入相对于当前窗口起点。每个读数给出完整原始值、真实采样时刻、来源秒数和最近样本时间差。缺测、采样空档和来源停止后的状态分别显示。
6. 命名并点击 **Save browsing view**，保存信号选择、各时钟窗口、布局和游标。重开 Explorer 默认恢复最近保存的配置，也可从下拉框打开其他配置。
7. 选择 **Continue with source**，从当前窗口进入现有分析或创建事件；已有重叠分析也可直接打开。模拟来源提供返回原过程调查会话的入口。保存的信号名称、单位和时间参考供事件曲线与专业报告使用。

[三份工业示例 CSV 与具体配置](examples/data-foundation/README.md) 包含 1 秒温度、2 秒 Unix 毫秒流量，以及不规则、缺测、重复／无效时间和长空档的压力数据。[实际验证记录](docs/signal-workspace-validation.md) 包含浏览器与旧库迁移结果。

质量统计保留全部来源行。无效时间行保留在原始 CSV 和质量统计中，定时数组及分析仅使用有效时间行，按时间稳定排序。有限测量值的统计包含无效时间行；可用样本数只计同时具有有效时间和有限数值的行。重复时间保留全部测量，游标选择最近时刻的第一条原始记录并标明重复数量。

长空档定义为超过正采样间隔中位数的 5 倍；其余偏离中位数超过 5% 的间隔标为不规则。样本片段表示记录分组，不表示连续观测。图表保留缺测和长空档断点；极值采样仅影响显示。需要统一采样或计算变量时，进入 Transformation Workspace。

## 把多个来源加工为派生数据集

1. 在 **Signal catalog** 或 **Signal Explorer** 选择信号，点击 **Transform selected signals**；也可以从侧边栏 **Transformations** 新建配置。
2. 检查单位和时钟。绝对来源按 UTC 对齐；相对来源先保存明确参考与偏移。配置保存后会固定其来源时钟及单位解释；需要使用最新元数据时，点击 **Use current source clocks and units**。
3. 选择共同覆盖、全部覆盖或自定义时间范围，以及采样间隔。自定义输入以页面显示的参考时刻为零点，输出 Dataset 以网格起点为第 0 秒。
4. 为每个来源选择目标单位、最近邻／线性／前值保持／窗口均值、最小值或最大值，配置最大允许间隔、重复时间策略和缺失处理。窗口聚合使用 `[t, t + interval)`；所有方法均保留来源覆盖边界。
5. 设置稳定表达式键，添加 `pressure_up - pressure_down`、`power / rated_power`、`rate(pressure)` 或 `diff(temperature)` 等变量。支持四则运算、abs、sqrt、log、exp、sin、cos、minimum、maximum、clip、diff 和 rate。clip/minimum/maximum 的标量界限使用首个输入的单位。复杂乘积需要指定输出单位，其数值使用界面展示的输入单位。
6. 检查实际曲线、填充前后有效数量、缺失比例、值域及测量／插值／保持／填充标记。点击 **Save configuration** 保存定义，或 **Generate new dataset** 保存并生成数据集。
7. 从派生 Dataset 进入现有 Analysis。默认只把原始观测依据计入覆盖率；可显式选择 **Include processed values** 纳入插值和填充值。Max-Z/PCA 的拟合、校准各需至少 30 行符合覆盖策略的基线数据；时序算法要求基线连续覆盖。低覆盖仍产生 abstain。
8. 从异常结果创建 Incident 并生成专业报告。Dataset、分析和事件均可展开 **Transformation provenance**，查看原始来源和处理步骤，返回原信号或 TripLens 会话。报告附录保存来源哈希、表达式、网格、参数和质量统计。

单位支持 °C/K/°F、Pa/kPa/MPa/bar、m³/s/m³/h/L/min、W/kW/MW、V/kV、A/mA、s/ms/min/h；rpm/Hz 需明确勾选转速语义。自定义单位只保持同名单位。温度相减得到 Δ°C/ΔK/Δ°F；绝对温度的乘除及相加会提示歧义。rate 按实际秒数差计算，首点缺失；简单速率单位可转换。

配置可以编辑；每次执行生成独立 Dataset，固定数值、时钟、配置修订号、来源文件哈希及逐点来源标记。重新执行保留全部旧数据、分析和事件引用。单次网格上限为 1,000,000 行和 10,000,000 个数值。统计填充取输出窗口内原始有效观测的统计值，可能包含整个窗口的信息，应按分析目的选择。

三份工业示例的设置与实际验收结果见 [变换工作流验证](docs/transformation-validation.md)。

## 持续维护一次事件调查

事件由用户创建和组织。一个检测区间可以成为事件的来源，同一事件可以包含相邻、重叠或由不同算法检出的多个区间。

- **基本信息**：保存标题、说明、起止时间、时间轴起点及调查状态。状态包括待调查、调查中、已形成结论、已归档；归档后仍可重新打开和修改状态。
- **数据与分析**：关联已有数据集、完整分析、异常区间或模拟记录。区间保留其所属分析、峰值、相关变量和数值贡献度；点击 **查看原始曲线** 检查对应窗口，点击 **打开原始分析** 返回该区间。
- **时间线**：按事件发生时间查看异常区间的开始、结束与峰值，以及人工观察和实验的观察截止。可筛选分析、类别、时间范围；点击报警定位来源曲线，点击笔记／证据／解释继续编辑，实验入口恢复保存的窗口和参数。没有观察时间的记录、状态和结论变更单独按操作时间显示。
- **分析比较**：选择本事件关联的分析，叠加报警区间，比较首次报警、峰值时间、持续时间和变量贡献；检查共同、独有或缺少共同观测的区间，并返回对应的原始分析。只关联区间时统计这些区间，关联完整分析时纳入该分析的全部区间。
- **共享观察窗口**：时间线、比较图与原始曲线共享选中窗口和时刻。可以调整起止、点击曲线或移动观察时刻，查看同一原始样本的多变量值及前一样本的变化量；样本读取完整测量，不使用图表采样值。
- **证据与解释**：添加可编辑的笔记、候选解释和证据。证据可以指向来源记录，并标记为支持、反对或待判断。实际观察时间和记录创建时间分别显示。
- **结论**：单独保存当前判断与后续安排。基本信息、调查记录和结论均有明确的保存按钮；保存成功后由服务确认。
- **模拟调查**：在过程调查中将当前候选解释、最近一次已完成结果或 Saved experiments 中的记录关联到事件。事件中可以直接查看工具输出与干预曲线，返回模拟会话时恢复该实验的观察窗口和参数。

普通 CSV 可以独立使用事件、笔记、统计分析和证据关系。需要模拟能力时，关联已保存的过程模型会话。事件总时间范围由用户维护；各来源保留自己的时间轴，关联不同数据集不会自动对齐或合并时间。

日期时间数据按照已保存的 UTC 起点换算后共享绝对时间轴；相对时间默认保留来源身份，也可以复用在数据工作区保存的显式时间参考和偏移。从检测结果创建事件时自动保存参考来源；此前未记录来源的旧事件保留独立时间轴，可在基本信息中选择「事件秒数的参考来源」。持续时间表示首末样本时间差，单点报警为 0 秒；abstain、长采样空档和窗口外不作为共同有效观测。

## 生成和归档调查报告

1. 从「事件」打开保存的调查，完成并保存说明、证据和当前结论。
2. 在「专业报告」点击 **生成报告**。报告读取当前保存的数据，预览包含封面摘要、事件演变、检测比较、真实曲线、调查记录、结论和技术附录；关联模拟实验时增加工具输出、实验参数及干预方案曲线。
3. 点击 **导出离线 HTML**。图表以 SVG 嵌入文档，无需启动 L5、连接网络或加载 React 即可打开。
4. 点击 **打印 / 保存 PDF**，在浏览器打印窗口选择「另存为 PDF」。报告使用 A4 页面、页边距、重复表头和图表分页样式；也可独立打开 HTML 后打印。PDF 使用本机浏览器的打印能力，无需安装服务端 PDF 引擎。
5. 事件修改并保存后，旧预览自动失效；再次生成反映最新内容。历史状态和结论的变更保留在时间线与报告中。可将 HTML、PDF 与事件 JSON 一同归档。

报告保留用户填写的原文。尚未填写的调查结论保持未记录；图表只使用真实保存的测量和分析结果。关键原始变量按关联峰值贡献选取前三项，附录保留分析参数和来源标识；CSV 未提供单位时按原始列名显示，不推断物理单位。

## 从模拟到可复用项目

1. 在 Workspace 打开 **Process simulator**，选择故障或健康工况，修改参数后点击 **Run new simulation**。每次调用 Python 计算新轨迹，无需重新构建前端。
2. 用时间滑块或数值框选择例如 `93`、`156.6` 秒；可以设置观察窗口起点。诊断、报警和传播仅使用窗口内截至该时刻的数据。过程诊断需要稳定的初始 20 秒基线；过早窗口会显示数据不足。
3. 查看全部 12 个候选；任意候选均可作为工作假设。**Investigation tools** 提供信号、变化点、时间窗、控制器、报警、传播、假设比较、传感器一致性、测量建议、SOP 和模型拟合试验。
4. 在 **Interventions** 配置动作、执行时间、预测终点，以及进料比例、冷却设定值、旁路流量或泵转速。观测拟合只用当前窗口；已知模型模式显式使用用户的模拟参数。可以比较多个动作与前一次参数结果，或设置分辨率搜索可恢复起始时间。
5. 点击 **Save dataset & model**。Datasets 中可运行通用算法，也可通过 **Open process investigation & interventions** 回到同一模型会话；工具、助手和干预结果自动保存，**Saved experiments** 可重开参数继续试验。

积分步长为 `0.05–1` 秒，单次仿真最多 100,000 步，恢复窗口搜索最多 3,000,000 个积分步；这些是数值稳定性与本机计算预算。预测中的越限使用物理压力。通用 CSV 仅开放其数据实际支持的统计监测；拓扑诊断与控制试验需要关联 TripLens 过程模型。

助手默认执行用户选择的确定性工具，也支持关键词路由。可选设置 `TRIPLENS_MODEL_ENDPOINT`、`TRIPLENS_MODEL`、`TRIPLENS_MODEL_API_KEY`，让外部模型总结当前观察上下文及 Python 工具结果。数值计算仍在 Python 中完成。

## 数据保存位置

默认保存在仓库下被 Git 忽略的 `data/`。事件使用独立稳定的 ID；事件信息、来源引用、笔记、假设、证据关系和结论保存于 `workspace.sqlite3`，不依赖浏览器存储。启动时自动添加事件相关表，保留已有数据库记录和数据文件。启动时可指定其他目录：

```bash
node scripts/python.mjs server.py --data-dir /path/to/l5-data
```

也支持环境变量 `L5_DATA_DIR`。重启时使用同一目录即可恢复。复制整个数据目录可以备份项目；删除 Workspace 会同时删除其事件、调查记录、数据集和通用分析记录；模拟会话及其试验保留在本机模拟库，并解除该 Workspace 的关联。

## TripLens 示例与研究

**TripLens examples** 保留原有 Live / Replay / Lab 教学示例；调查界面通过同一运行时引擎创建场景和比较观测。示例中的物理关系和诊断器只属于各自的模拟过程。

`benchmarks/` 保留 Tennessee Eastman、时间监测器、PCA/DPCA、独立种子及六工况研究。Workspace 直接复用现有时序、DPCA、自适应检测和覆盖率算法，通用 Max-Z/PCA 在 `l5/monitoring.py` 中共享。52、53、18 通道数据之间不做物理含义映射。

统计相关信号表示偏离贡献；过程诊断的证据得分不等于概率，模型预测不代表工厂控制保证。普通 CSV 不会因列名相似而自动获得物理模型能力。
