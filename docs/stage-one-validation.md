| 使用问题 | 修复与验证 |

| Explorer 进入 Analysis 后，刷新会丢失 Dataset、选中信号和观察窗口。 | 用 URL 查询保存上下文；信号名按独立参数编码。浏览器恢复温度的 200–599 s 窗口，DOM 覆盖包含逗号、空格和加号的名称。 |

| TripLens 的“已保存数据”链接没有具体 Dataset ID。 | 链接指向实际保存的数据，并提供与双水箱一致的直接创建检测实验入口；在浏览器从模型打开准确数据并完成实验。 |
| TEP 研究／训练配置／矩阵选择在刷新后恢复为默认值。 | 协议、study、A/B/C、指标及故障／算法选择进入 URL；刷新后恢复 B／最终名义检出／故障 3／DPCA-Q。协议名称改为面向用户的名称。 |
| 长结果页自动定位后，侧边导航离开屏幕。 | 桌面导航保持可见并独立滚动；390 px 下恢复普通横向导航，检查事件、实验和两个模型及 TEP 均无页面横向溢出。 |

## 浏览器工作流

生产服务使用 8792（CSV／模型）、8793（扩展 TEP）、8794（原始 TEP）端口。目录为本轮可保留的验收副本，历史原件继续保存。

| 工作流 | 实际完成内容 |
|---|---|
| 普通 CSV | 通过浏览器文件选择器导入温度文件；检查缺测，编辑单位与设备；保存 Explorer 视图，进入 Analysis 并刷新；运行 Robust Max-Z，保存 380–434 s 温升事件的假设、来源证据与结论，下载 Incident HTML。 |
| 多源变换与实验 | 导入毫秒 Unix 流量和相对秒压力；显式关联时钟并设置压力 +25 s；恢复三个选中来源的 250–470 s 视图。将压力换算为 MPa、重复时间取均值，建立 1 s 网格与压力变化率，生成 496 行 Dataset。使用 0–139 s 基线运行九算法，9/9 成功；保存研究结论、比较时间线、关联事件并下载实验 HTML。 |
| TripLens | 创建泵退化场景并保存模拟；在 80 s 截止窗口运行传感器一致性工具，比较减小进料／备用泵方案，干预开始 83.17 s、预测至 150 s。保存 Dataset，经修复后的直接入口运行两算法实验，2/2 成功；建立事件并导出 HTML，重开历史参数。 |
| Coupled-Tank | 创建泵退化场景，故障起点 40.37 s；运行观测质量平衡工具，比较调泵／备用泵方案。保存 Dataset，运行两算法实验，2/2 成功；关联模拟、干预和检测结果，保存结论，下载实验和事件 HTML。历史结果恢复 0–80 s、83.17 s、150 s 及对应动作参数。 |
| TEP 原始案例 | 从原始协议入口打开已有 72 项成功实验，选择 fault 1／run 1 比较九算法；实际下载包含 142 幅 SVG 的完整实验 HTML。 |
| TEP 扩展研究 | 检查缓存来源、预览并导入一份独立正常运行；浏览已保存的 585／1,755 项研究，切换 A/B/C；查看故障矩阵、三份逐运行结果及故障 3 正常背景对照。刷新恢复 B 配置和选中单元格；打开已有 fault 1／run 1 的九算法 Incident。 |

CSV 和两模型的浏览器流程共保存 14 项分析结果。独立 HTTP 检查还覆盖两个模型各九算法，以及同一实验出现部分失败后仍能查看旧结果、修改有效基线并重新执行的过程：首次 3 成功／6 失败，修正基线后 9 成功，先前成功结果未改变。

浏览器下载的六份 HTML 在回执中记录字节数、SVG 数量与 SHA-256。它们包括普通事件、派生实验、两模型的调查材料和原始 TEP 实验；报告来自实际保存数据。
