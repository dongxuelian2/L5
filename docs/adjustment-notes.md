# Adjustment report → implementation

2026-10-05 · TripLens v0.2

本轮以调整报告的调查闭环为主线，保留现有浏览器 TUI 和轻量技术栈。视频制作已暂停，既有素材保留在本机忽略目录中。原 PROCESS 01 保留用于连续播放；新增 PROCESS 02 支撑多事故调查。

| 报告主题 | 本轮实现 | 边界 |
|---|---|---|
| 未知故障与多证据诊断 | 12 类故障、18 通道、正反证、评分分解 | 规则支持分，不是概率；不读取场景标签 |
| 分叉拓扑与控制器 | 14 条分类边、两个 SP/PV/OP/FB 回路、限幅/速率限制 | 自建低阶过程模型 |
| 工具调查 | 结构化审计和白名单工具调用 API | 本地确定性策略，未调用 Nemotron |
| 连续恢复窗口 | 每秒完整枚举 7 类动作，共 1,547 分支/会话 | 1 秒分辨率、240 秒有限时间窗、依赖拟合假设 |
| 操作目标 | 压力裕度、产量损失、质量损失、冷却消耗 | 三项推荐按各动作自己的最后安全时刻比较 |
| 报警洪泛 | 激活/重复/恢复、条件/分组、洪泛、抖动分类、整治建议 | 分组来自显式过程区域；不自动执行抑制 |
| 证据健康 | 缺失、冻结、过时、异常跳变、时间间隔检查 | 使用独立通道约束评分；未覆盖所有工业坏数据模式 |
| 主动诊断 | 排序后的区分性检查与竞争假设 | 启发式优先级，非校准的信息价值 |
| SOP | 结构化冷却丧失规程与前置条件验证 | 未实现任意自然语言文档解析 |
| 日志与历史 | 操作员备注、可持久保存的 JSON 指纹、相似度与原因 | 本浏览器存储；备注不直接改变物理证据评分 |
| 外部数据 | 本地 CSV 回放分析、输入校验、结构化工具 API | 无 MQTT / OPC UA；固定基线，非滚动流式检测 |
| RCA | 完整 Markdown / JSON 档案与工具记录 | 无原生 PDF 导出 |
| 验证 | 36 故障参数变体 + 3 正常窗口；29 项测试 | 非独立 TEP 评测，不推断生产准确率 |
| 工作区 | INVESTIGATE / LEARN，保留 LIVE / REPLAY / LAB | 两代数值模型结果分别标识 |
| NVIDIA / Nebius | 原适配器与新的结构化工具协议保留 | 按当前要求继续暂缓真实服务接入 |

重要计算约定：数据窗口前 20 行必须属于稳定工况；压力传感器偏置与物理压力分离；反事实使用观测拟合的领先假设而不是生成器真值。未知根因、混合故障、任意新工况及长期稳定性尚未独立验证。

浏览器验证覆盖早期证据隔离、传感器偏置/冻结、干预窗口边界、跨刷新事故记忆、CSV 往返、RCA 下载、窄屏布局及保留的原工作区。远程 CI 状态以 GitHub 实际运行结果为准。
